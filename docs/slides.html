2-Layer Architecture

Layer 1 — Static Analysis

📥 Source Files (.py .js .java .php)
↓
🔧 Tree-sitter AST Parser
↓
📋 Rule Engine (YAML)
↓
🔗 Call Graph + Taint Engine
↓
⚠️ Vulnerability Findings

Layer 2 — AI Verification

  • Mỗi finding được gửi cho Gemini AI
  • AI xác nhận: đây có phải lỗi thật không?
  • AI đề xuất cách fix cụ thể
  • Confidence score được gắn vào report

What We Built

🌳 AST-Based Analysis

Dùng Tree-sitter để parse code thành Abstract Syntax Tree. Không dùng regex — hiểu cấu trúc ngôn ngữ thật sự, tránh nhiễu.

expr = request.args.get('id')

🔗 Taint Propagation

Theo dõi luồng dữ liệu từ source → qua assignments/aliases → đến sink. Biết được đường đi của data.

uid = req.args.get('id')
q   = "WHERE id=" + uid
db.execute(q)  # ← CAUGHT

📂 Cross-file Tracking

FunctionIndex + ImportResolver cho phép theo dõi taint xuyên file qua static imports. Level-B inter-procedural.

# utils.py → source
# app.py   → sink
# Tool nối 2 file lại!

🤖 AI Verification

Gemini API xác nhận từng finding. Giảm false positive. Cung cấp remediation advice cụ thể theo context.

📋 YAML Rule System

Rules được định nghĩa ngoài code trong YAML — dễ mở rộng, không cần sửa source code để thêm rule mới.

🧪 44 Unit Tests

Test coverage đầy đủ: rule loading, AST parsing, taint analysis, cross-file detection. Tất cả pass 100%.
