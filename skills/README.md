# Aegis-SAST Local Skill Pack

This folder contains a local skill pack for turning the current repository into a thesis-scale SAST agent project.

## Skills

- `aegis-sast-agent`: end-to-end workflow orchestration
- `aegis-sast-architecture`: architecture mapping and trust-boundary analysis
- `aegis-sast-rule-author`: rule design, plugin changes, and language expansion
- `aegis-sast-triage`: finding normalization, evidence scoring, and false-positive control
- `aegis-sast-remediation`: safe remediation planning and patch writing
- `aegis-sast-benchmark`: benchmark design, baselines, and thesis evaluation

## Suggested Use Order

1. Use `aegis-sast-architecture`.
2. Use `aegis-sast-agent` to plan the scan or thesis workflow.
3. Use `aegis-sast-rule-author`, `aegis-sast-triage`, or `aegis-sast-remediation` based on the workstream.
4. Use `aegis-sast-benchmark` whenever you need results fit for a graduation report or defense.
