# Knowledge Card Library

This directory contains built-in YAML knowledge cards for Aegis-SAST triage.

## Purpose

- provide structured security context for normalized findings
- capture common sources, sinks, sanitizers, and false-positive patterns
- seed the future agent workflow with local security knowledge

## Strategy

- generic cards cover weakness-level guidance across languages
- language cards capture framework and ecosystem specifics for Python, JavaScript, and Java

These cards are intentionally lightweight in v1 so they can be extended during the thesis implementation.
